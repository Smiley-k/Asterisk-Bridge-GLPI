Asterisk-Bridge-GLPI

**Попап звонка, click-to-call и заявки из телефона — прямо в GLPI.**

Asterisk Bridge связывает **Asterisk / FreePBX** с **GLPI**. Звонит телефон — GLPI показывает
карточку звонящего. В один клик: перезвонить, открыть карточку или создать заявку. Больше никакого
копирования номеров руками.

##  Что умеет

- **Попап звонка** — карточка звонящего (ФИО, должность, город) при каждом входящем
- **Click-to-call** — клик по номеру: сначала звонит ваша трубка, потом набирается вызов
- **Панель быстрого набора** — справочник сотрудников + клавиатура на любой странице GLPI
- **История звонков** — активные и последние, по каждому оператору
- **Заявка из звонка** — Инцидент/Запрос с категорией в один клик
- **Английский / русский** интерфейс, персонально
